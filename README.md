# The Perfect Storm: Understanding the 2008 Housing Market Collapse

The Perfect Storm is a collaborative course project examining economic and housing indicators associated with the 2008 U.S. housing market collapse. The team combined exploratory analysis, written context, and interactive visualizations to present changes before, during, and after the crisis across the 2000–2015 period.

## Final presentation

[View the working final presentation and interactive visualizations](https://williamguy11.github.io/Final_Project_209/)

The presentation covers interest and inflation rates, the Consumer Price Index (CPI), state and national House Price Index (HPI) measures, mortgage originations, vacant and renter-occupied properties, foreclosures, and unemployment.

## Collaboration and my contribution

This repository preserves the project substantially as the team submitted it for the course. It reflects collaborative research, analysis, interpretation, and presentation work.

My primary individual contribution was developing the interactive Observable visualizations used in the final presentation.

## Technologies

- Python and Google Colab
- pandas and NumPy for data preparation and exploratory analysis
- Matplotlib, Seaborn, and Plotly for exploratory visualization
- Observable for the final interactive visualizations
- HTML and CSS for the presentation page

## Data represented

The original course workflow used shared CSV datasets covering:

- House Price Index measures, including state-level and national data
- Interest, inflation, and 30-year mortgage rates
- Consumer Price Index, consumer credit, consumer spending, and credit-card debt
- Mortgage originations
- Foreclosures
- Housing inventory, vacancies, and renter-occupied properties
- Unemployment

## Repository contents

- `index.html` — final presentation page with embedded Observable visualizations
- `FinalProject.ipynb` — collaborative exploratory analysis notebook

## Limitations and reproducibility

The original analysis relied on shared course datasets and Google Drive/Colab workflows that are not fully contained in this repository. As a result, the notebook does not run from a clean clone without access to the original data and path setup. The repository is retained primarily as a record of the submitted collaborative project; the deployed final presentation and its embedded visualizations remain available through the link above.
